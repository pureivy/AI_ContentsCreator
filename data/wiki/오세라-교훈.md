- 데이터랩·자동완성 원자료가 없을 때는 수치를 추정하지 말고 '법령 검색' 등 대체 소스로 즉시 재시도하되, 확보된 정성적 사실과 미확보 항목을 표로 분리해 다음 단계 담당자가 바로 알아볼 수 있게 넘겨야 한다.

## 갱신 (2026-07-01)
- 데이터랩 API 접근 불가 시 블로그 SERP 문서수 같은 대체 지표를 즉시 확보해 공백을 메우되, 대체소스의 한계(경쟁지표일 뿐 검색량 아님)를 명시해 후속 왜곡을 막는다.

## 갱신 (2026-07-01)
- 주제어 자체가 다의어·모호할 경우 SERP 조회 전에 대상 정의(고유명사/브랜드/일반어)부터 확정해야 문서수 지표가 무의미해지지 않는다.

## 갱신 (2026-07-01)
- 데이터랩 API 접근 불가 확인 시 즉시 대체 소스(자동완성 실측·경쟁 콘텐츠 스크래핑 등) 최소 2개를 찾아 공백을 메우고, 타 부서 담당 영역은 표로 명확히 분리해 중복 조사를 피한다

## 갱신 (2026-07-01)
- 데이터랩·자동완성 API 접근 불가를 조사 착수 전에 먼저 검증하고, SERP 문서수 등 대체 소스도 검색어 오염(중복 입력) 여부를 교차 확인한 뒤 수치를 확정한다.

## 갱신 (2026-07-02)
- 네이버 데이터랩·자동완성 API가 막히면 법령 검색 같은 무관한 대체소스 대신 뉴스 검색결과수·커뮤니티 언급량 등 주제 연관성 높은 대체 소스부터 우선순위를 매겨 시도한다.

## 갱신 (2026-07-03)
- 데이터랩·자동완성 접근이 막히면 SERP 문서수를 경쟁밀도 대체지표로 즉시 확보하되 검색량과 혼동되지 않게 라벨링한다

## 갱신 (2026-07-03)
- 데이터랩 접근 불가 시 SERP 문서수를 대체지표로 즉시 표기하고 '검색량 아님'을 명시해 혼동을 차단한다.

## 갱신 (2026-07-03)
- 페르소나·역할 문구를 검색어에 그대로 섞으면 SERP가 오염되니, 조사 키워드는 대상 주제어만 순수하게 분리해 질의할 것

## 갱신 (2026-07-03)
- 데이터랩 상대지수 급등락은 검색광고 키워드도구로 절대량을 교차검증하기 전까지 '선행계획 패턴' 등 원인 해석을 확정 사실로 서술하지 말 것

## 갱신 (2026-07-04)
- 경쟁문서수(SERP 지표)와 실제 검색량 지표를 혼동 표기하면 후속 팀이 데이터를 오독하므로, 지표 유형을 반드시 명시적으로 구분해 라벨링한다.

## 갱신 (2026-07-04)
- 경쟁 문서수만 제시하지 말고 검색량 데이터와 대조해 '경쟁 밀도 대비 실수요' 판단까지 함께 표기한다.

## 갱신 (2026-07-07)
- 입력 데이터 오염 여부를 조회 전에 먼저 문자열 패턴으로 검증해 무효 조회 낭비를 막을 것

## 갱신 (2026-07-07)
- 플랫폼 합산으로 '상위 10개'를 채워도 단일 플랫폼 완전 표본이 아니면 반드시 표본 한계를 명시해야 한다.

## 갱신 (2026-07-07)
- 정량지표 부재를 지적만 하지 말고 즉시 도구 호출로 대체지표(경쟁밀도 등)를 직접 확보해 보고서에 채워라.
