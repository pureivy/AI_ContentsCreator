# 📋 [리서치·SEO팀 최종 산출물 v2] 콘텐츠 브리프 — 여름 장마 습도/제습

**작성:** 서다인(리서치·전략 디렉터) | 2026-07-03 KST (Round 1 반영 갱신)
**취합 대상:** 오세라(트렌드 리서처), 김도현(SEO 전략가)
**검증:** 정하람(Round 1) — 표기 오류 2건 수정 반영
**발행 등급:** 🟡 **조건부 발행(리스크 B등급)** — 정량 데이터(실검색량·의도별 비중%) 공백, 정성 근거 3중 이상 일치로 조건부 확정

> **Round 1 반영 요약:** ①정성/정량 라벨 통일 ②SERP "유효 1건 포함 참고용" 표현으로 모순 해소 ③권장 제목 28자로 축약 ④키워드 본문 중반 재노출 추가 ⑤SERP 관련성 필터 기준 명문화

## 0. 발행 리스크 등급 및 데이터 공백 명시 (검수자 재추적용)

| 구분 | 상태 | 근거 비중 |
|---|---|---|
| 정량(월간검색량·경쟁도) | ⚠️ **공백** — 데이터랩/검색광고 API 접근 불가, 메인 시드 1건만 월 20회 확보(검증 완료 아님, 단일 소스) | — |
| 정성(SERP 제목·문서수·의도구조) | ✅ 확보 — 오세라·김도현 **독립 3중 이상 일치** | 主 |

**⚠️ SERP 유효성 한계 명시:** 현재 수집 SERP는 5건이나 그중 **주제무관 4건(재테크·장마 관련주 등) 혼입, 유효 1건**. 따라서 이하 "SERP 5건"은 **"SERP 5건(유효 1건 포함, 참고용)"**로 읽어야 하며, C 공백 해소(10건 재수집) 전까지 정성 근거의 신뢰도는 제한적임. [근거: 오세라·김도현 SERP 수집 결과]

**공통 데이터 공백(에스컬레이션 대상):**

| # | 공백 항목 | 필요 자료 | 담당 |
|---|---|---|---|
| A | 5개 키워드 개별 실검색량 | 데이터랩/검색광고 API | 데이터팀 |
| B | 의도 4유형 검색량 비중(%) 확정치 | 검색광고 도구 | 데이터팀 |
| C | 상위 10건 SERP(현 5건, 유효 1건·주제무관 4건) | **주제 관련성 필터** 적용 재수집 | 마케팅팀 |

→ 정량 3개 공백은 분리 에스컬레이션. 본 브리프는 정성 근거 기반 **조건부 확정**, A·B·C 완료 시 Round 2 갱신. [근거: 오세라·김도현 발행 보류 사유 일치]
