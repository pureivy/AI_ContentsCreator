# 학습 정리 (누적 교훈 압축, 2026-09-27)

- **SERP 직접일치 0/5(또는 저조) 즉시 오염 확정 → 파생어 병렬 교차조회**: CEO 지정 시드어라도 예외 없이 적용. 절단·오타·동음이의어·인접 카테고리 오염 등 원인을 먼저 명시하고, 상위어·동의어·행위어·시기어 2~4개로 병렬 조회해 그 자리에서 결과까지 완료 제출한다("조사 예정" 선언 금지).

- **문서수≠경쟁강도, 오염률(상위5 직접일치율)로 판정**: 완전 오염(0/5)은 문서 없음이 아니라 검색의도 세분화 실패 신호. 동음이의어로 인한 문서수 부풀림 가능성도 검증하며, 하위 타이밍형·구체형 키워드로 재분기한다.

- **커버리지 표 선공개 + 미조회 칸은 근거로 미사용**: 씨앗어×채널(자동완성·데이터랩·SERP·유튜브) 매트릭스를 조사 착수 전 표로 공개. CEO 지정 시드어는 상위 개념어로 대체 조회하지 말고 반드시 시드 자체를 별도 조회한다.

- **데이터 없음은 명시, 추정 절대 금지**: 데이터랩이 상위어로 대체 응답하거나 자동완성 공백 시 "데이터 없음"으로 명시하고 필요 자료(검색광고 API 등)를 병기. 반환값은 원문 그대로 인용하고, 본문 미열람 시 "없다" 대신 "제목 기준 미표기"로 서술한다.

- **다건 배치 요청 시 회신 수 검증 필수**: 데이터랩·SERP 등 다건 조회는 요청 수 대비 회신 수를 즉시 검증하고, 누락분은 개별 재조회로 채워야 사이클을 종료할 수 있다.

- **복합/광의 시드어는 사전 분해 후 조회**: 복합 날짜·조합형 시드는 단일 명사구로 분해해 검증하고, 광의 시드(예: "가을 나무")는 구체 행위어(전정·심기 등)를 포함해 처음부터 조회해 도감성 오염을 예방한다.

- **표본 부족 시 보강 후에만 완료 보고**: 단일 시드어 표본 10~15건 미만이면 파생어로 보강. 시계열·계절 스파이크 판단은 단일 지수/단일 SERP가 아닌 최소 2개 이상 연관어의 패턴 일치로 근거를 보강한다.

- **체크리스트 완결 처리 원칙**: 여러 씨앗어/실패 패턴을 동시에 다룰 때는 착수 전 항목별 체크리스트를 만들어 SERP 확인·수치 회수·오염률 검증을 모두 완료하고, 절반만 끝내고 다음으로 넘어가지 않는다.
