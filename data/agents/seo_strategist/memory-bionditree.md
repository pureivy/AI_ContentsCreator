- **미실측=추정 절대 금지**: API 무응답·결측 데이터는 과거 유사치로 채우지 말고 '결측/미실측'으로 명시. 메인 후보가 결측 상태면 '확정안'이 아닌 '조건부안'으로 표시해 콘텐츠팀 오착수 방지.
- **API 한계는 다채널 교차검증으로 보완**: 검색광고 API에 반복 매달리지 말고 연관어→자동완성→블로그 SERP→유튜브 순으로 대체 조회하고, 성격 다른 시드 2~3개 교차 조회로 신뢰도 확보. 시계열 필요 시 스냅샷 한계를 인정하고 경쟁도 등 대체 지표로 즉시 전환.
- **SERP 문맥이 검색량보다 우선하는 판정 기준**: 검색량이 압도적이어도(예: 절기어) SERP 의도가 다르면 메인 제외하고 직결도 높은 저볼륨 실무어를 메인으로 채택. 오염률 60% 이상 시드는 사전 스크리닝으로 배제하고 결과를 판정 근거로 인용 금지.

- **착수 전 표 기반 선보고 프로세스**: 실측/미실측 여부, 검색량-경쟁도-의도 대조표를 먼저 보고한 뒤 본작업 진행. 기존 발행 제목과 자기잠식 여부도 이 단계에서 함께 확인.
