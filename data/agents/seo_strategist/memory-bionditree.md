# 키워드 리서치 핵심 원칙 (압축본, 2026-10-23)

- **선언 금지, 같은 턴 완결**: "조회하겠습니다"로 끝내지 말고, 도구 호출 결과(검색량·경쟁지수)를 반드시 같은 턴 안에서 숫자로 산출해 제출한다. 부분 결과는 "남은 작업 목록"과 함께 중간 제출하되 최종본처럼 포장하지 않는다.

- **무응답 처리 원칙**: 시드가 연관어만 반환하거나 월 10미만이면 재조회하지 말고 즉시 '무응답/저수요'로 확정 → SERP 문서수나 데이터랩 시계열 등 대체 지표로 전환한다. 단, 연속 무응답 시에도 동의어·행위어 순서 교체·원형어 분해 등 1회 피벗은 먼저 시도하고, 그래도 안 되면 중단한다.

- **메인 키워드 선정 3조건 동시 충족**: ①볼륨(최소 300+ 등 명확 임계값) ②검색의도 일치(SERP 상위 5건 적합도 수치화) ③경쟁도 중간+경쟁콘텐츠 선점 부재. 서브 키워드도 동일 기준으로 전수 실측해 미달 항목을 조기에 걸러낸다.

- **데이터 오염 즉시 차단**: 복합어(동음이의어, 생활폐기물 카테고리 중복 등)나 연관어가 2~3회 연속 타 카테고리로 이탈하면 즉시 폐기하고, 원형어+단일어+행위어로 분해해 재조회한다.

- **지표 교차검증**: 경쟁도 '높음'이 SERP 상위 5건과 무관하면 재검증하고, 저볼륨이라도 실수요(유튜브/SERP) 있으면 폐기 대신 확장어로 전환. 출처 불명 종합 라벨 수치는 검색광고 실측으로 재확인한다.

- **개별 조회 원칙**: 키워드를 묶어서 조회하면 첫 단어만 실제 수치가 반환되므로, 핵심 후보는 처음부터 단일 키워드씩 개별 조회한다.

- **완결성 체크**: 표/문장이 중간에 끊기지 않도록 모든 키워드(보조 포함)의 선정 사유·근거를 완결된 형태로 마무리하고, 최소 개수(5~8개) 충족을 자체 확인 후 CPC·검색 추이·자기잠식 가능성까지 빠짐없이 채워 제출한다.

- **보고 형식 고정**: 완료/미완료 분리 + 볼륨-경쟁도-의도-조회시점 대조표를 선제 제시하고, 전량 실측 완료 후 일괄 취합 보고한다.
