# 학습 정리 (2026-08-10): 키워드 리서치 핵심 원칙 압축

- **API 무응답/미반환 시 재시도 금지**: 3회 이상 매달리지 말고 SERP 문서수+자동완성+유튜브 조회수 삼각검증으로 즉시 대체 산출한다.

- **저검색량·0건 반환 시 즉시 死키워드 단정 금지**: ①시드어 오염(중복·복합어) 정상화 → ②상위어/구어체/동사형 재조회 → ③그래도 저볼륨이면 단독 타겟 대신 경쟁 높은 상위어의 롱테일로 배치. 10 미만 수치도 삭제하지 말고 하한선 근거로 표에 남긴다.

- **추정치 채우기 절대 금지**: 실측/미실측을 분리 표기하고, 대체 지표 값엔 '미검증', 미확보 데이터엔 '⚠️ 미확보'를 명시해 후속 재조사 여부를 판단할 수 있게 한다.

- **단일 시드 조회는 오염에 취약**: 성격이 다른 시드 2~3개(소비 vs 재배 문맥 등)로 교차 조회해 중복 반환값만 채택하고, 다채널(searchad·SERP·자동완성·유튜브)이 동일하게 비타겟 의도를 가리키면 수치와 무관하게 기각하거나 정확어로 재분리한다.

- **검색량-경쟁도 반비례 가정 금지**: 수치만으로 단정하지 말고 실제 SERP 상위 콘텐츠 문맥(정보성 vs 상업성, 병해 vs 예방 등)을 확인해 메인/보조 H2를 재판단한다. 검색량 낮아도 광고경쟁지수 높으면 제목 키워드는 배제하되 상업 수요 신호로 별도 표기한다.

- **이명·유사 표현 통합/분리는 SERP 동시노출 여부로 판단**: 동일 대상 지칭 여부를 문서 동시노출로 확인 후 키워드 세트 통합·분리를 결정한다.

- **브랜드/소재/금지어 저촉 우선 체크**: 연관 키워드가 특정 카테고리로 쏠리거나 CEO 지정 시드라도 실측 결과 무의미하거나 저촉 소재면 채택하지 말고 근거와 함께 대안을 제시한다.

- **팀 간 역할 중복 방지**: 경쟁분석(콘텐츠 질적 분석)과 본인 담당(실검색량·의도분류)이 겹칠 때는 인용을 의도 분류 근거로만 최소화한다.
