# 키워드 리서치 핵심 원칙 (압축본, 2026-09-25 갱신)

- **월 검색량 10 미만 = 즉시 배제 원칙**: 예외 없이 컷오프 적용. 단, 진공/선점형 롱테일은 사유 명시 후 보조·태그로만 채택 가능.

- **선언 금지, 즉시 실측 제출**: "조회하겠다"는 선언으로 산출물 마감 금지. 배정된 시드는 모두 검색광고 실검색량+경쟁지수를 순차 단일조회로 직접 확보해 수치로 보고. CEO 지정 시드도 예외 없음.

- **저볼륨/무관 반환 시 즉시 피벗**: 시드가 월10 미만이거나 3개 이상 반복 저볼륨이면 대기 없이 인접 키워드·상위 개념어·품종명 세분화로 즉시 전환 조회. 오염된 무관 카테고리 반환은 알고리즘 오분류로 간주, 상위개념·계절형 피벗 1회로 신속 마무리(무한 재조회 금지).

- **복합/조합 키워드는 데이터 부재 가능성 높음**: 단일 시드 순차 조회가 실측 성공률 높음. 복합어가 죽으면 개별 품종명·단일 시드로 쪼개 재조회하거나, 실수요 확인된 메인 키워드의 롱테일 질문형으로 재설계.

- **경쟁도·검색량은 반드시 대비 표기, 결측은 추정 금지**: "경쟁 낮음=기회"로 오독되지 않도록 두 지표 분리 병기. 결측 시 검색광고→자동완성→블로그 SERP→유튜브 순 교차검증, 미조회 키워드는 ⚠️ 데이터 없음으로 명시(추정 채택 금지).

- **의도 검증 필수**: 다의어·총칭어·단독 수종명 등은 검색량이 높아도 의도(B2B/B2C, 응급/일반 등) 불일치 시 배제하거나 조합형(수종+월동 등) 실측이 나올 때까지 후보 확정 보류.

- **착수 전 실측 대조표 선보고**: 볼륨-경쟁도-의도-배율-조회시점 표를 먼저 제시하고 기존 발행물과 자기잠식 여부 확인 후 본작업 진입. 최소 5개 후보를 3축 비교해 메인+보조 동시 확정.
