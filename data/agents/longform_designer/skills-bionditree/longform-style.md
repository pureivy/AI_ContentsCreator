# 롱폼 장면 스타일 B — 연필 선화 + 포인트 색 하나 (2026-10-23 사장님 선택)

부품 쓰는 법은 키트 문서(KIT_API_B.md)가 정한다. 여기는 그림을 고를 때의 판단 규칙이다.

## 연필(키트 부품이 지킨다 — 흉내 내지 말고 부품을 쓴다)
- 연필 3단: H(구조선·먼 대상·밝은 해칭) / 2B(윤곽·짙은 해칭) / 6B(가장 앞 강조선·핵심 그림자·접촉 그림자).
- 해칭은 형태를 따른다(줄기·가지·화분 = 둘레를 감는 호, 열매·뿌리분 = 고리). 명암은 해칭 → 크로스 해칭 3단.
- 명암 5요소(빛은 왼쪽 위): 하이라이트는 비움 / 중간 톤 두 단계 / 핵심 그림자 띠(외곽선에서 떨어진 부드러운 띠) / 반사광(중간 톤보다 어둡게) / 투영 그림자(가장 진하고 선명한 곳은 접촉점, 멀수록 흐림 — 땅에 선 나무·화분은 반드시).
- 문지름은 땅 그림자·흙 단면·배경에만. 흙은 점묘. 지우개 하이라이트(감 광택·껍질 능선·잎맥).
- 그리는 순서: H 구조선 → 2B 윤곽 → 해칭 → 6B 강조 → 포인트 색.

## 판단 규칙(반드시)
- 포인트 색은 지금 낭독이 말하는 것에만, 그 박자에 켜고 끈다. 한 화면에 덩어리 하나(많아야 둘).
- 식물은 종 프리셋으로만 — 작업 지시의 '이 묶음 수종' 표에 적힌 species 값 그대로. 임의 모양·다른 수종 흉내 금지. 프리셋이 없는 수종은 species="generic" + 장면 맨 위 주석에 '일반형'(보고됨).
- 실물 대조용 사진이 있으면 그리기 전에 한 번 열어 잎·꽃·열매·수형·껍질을 확인한다.
- 계절 = 문장의 때. 겨울·잎 진 뒤 = 잎·열매 없이 겨울눈만(season="winter").
- 화면 글자는 그 문장에 나온 말·숫자만. 달력·눈금도 문장에 나온 달·수치만.
- 비유는 글자 그대로 그리지 않는다(밑천 → 동전 금지). 비유가 가리키는 실제 대상(뿌리·줄기에 저장된 양분)을 그린다.
- 짧은 연결 문장도 빈 화면 금지 — 앞 문장의 대상을 작게 이어 그리고, 이번 문장이 새로 말하는 것을 주인공으로.
- 실촬영 끼움 카드는 문장이 실제 모습·상태·크기·색·질감을 말할 때만, 주인공을 가리지 않는 빈 쪽에. ★ 지정 장면은 반드시 한 번.
- 사람 손은 그리지 않는다(2026-10-23 — 코드 손은 마네킹처럼 보인다). 쥐기·누르기·풀기 같은 동작은 대상의 변화(뿌리분이 풀리는 모양, 흙이 눌린 자국)와 화살표·순서 번호로 보여 주고, 실제 손 동작이 꼭 필요하면 실촬영 끼움 카드로.
- 진행자 비온이가 켜진 편(2026-10-23): 장면은 화면 전체(배경·땅은 왼쪽 끝까지)로 그리되 왼쪽 아래 x<420·y>560 에는 주인공·라벨·끼움 카드를 두지 않고(비온이가 그 위에 선다), 문장마다 비온이 몸짓을 `bioneeCues` 로 0~3개 고른다 — 문장이 말하는 그림을 그 낱말 시각에 `point`(그 부품 좌표), 경고엔 놀람·걱정 얼굴, 질문엔 생각, 요령엔 엄지·끄덕. 팻말(`holdSign`)은 이 문장에 나온 낱말로 6자 이내만.
- 비온이도 쉬어야 산다 — 이웃 문장과 같은 몸짓을 잇지 않고, 가만히 두는 문장(`bioneeCues = []`)도 섞는다. 큰 동작(걷기·깡충·팻말)은 한 문장에 하나.
