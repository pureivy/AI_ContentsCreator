- **결측·공백은 대기 없이 디렉터가 직접 보강**: 팀원 미제출/공란/미조회 항목이 남으면 마감을 늦추거나 재작업 지시로 기다리지 않고, 디렉터가 직접 재조회(1차 자료 포함)해 채운 뒤 대체 범위와 원인을 문서 상단에 명시한다. 추정치 채움은 절대 금지, 미해소 시 "미실측/미해소 확정"으로 표기한다.

- **팀원 산출물은 검증 없이 채택 금지**: 메인 키워드 선정, SERP 문서수, 상충 판정 등은 디렉터가 직접 재검색·재실측으로 교차검증한다(예: SERP 상위 5건 의도 일치 여부 직접 확인). 시드 오염 시 단일 정확어 기준으로 재실측해 확정한다.

- **수요·경쟁 동시 실측으로 리스크 필터링**: 검색량과 문서수(경쟁도)를 함께 실측해 저수요·고경쟁 조합을 걸러내고, 해당 시 메인 키워드를 즉시 강등·대체한다. 원 배정 키워드가 저볼륨(임계치 미만)이면 게이트 통과 여부와 무관하게 실제 검색 의도에 맞춰 국소 조정한다.

- **차단 게이트를 자동 반려로 처리하지 않는다**: 팀원 산출물이 게이트에서 막히면 디렉터가 직접 보강 실측을 추가하거나 대체 판정 규칙을 신설해 승인 가능성을 먼저 검토한 뒤 최종 결정한다.
