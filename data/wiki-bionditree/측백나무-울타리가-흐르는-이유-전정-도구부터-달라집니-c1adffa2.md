# 브리프 검토 — 측백나무 울타리 전정 도구 (라운드 1 갱신판)

## 1. 사실 스팟체크 (가장 위험한 주장 5건)

1. **"측백나무" YoY 98→72(→53)** [근거: 데이터랩트렌드] — 봄 정점·가을 하강이라는 결론과 수치 방향이 일치. 올해 9월 값 결측을 "데이터 없음"으로 명시하고 프레임 결론에는 영향 없다고 분리한 처리가 타당함. 통과.
2. **`전지가위` 14,490(4,090/10,400)** — PC+모바일 합산이 정확히 총량과 일치(4,090+10,400=14,490). 수치 내적 정합성 확인. 통과.
3. **`측백나무` 12,290(1,390/10,900)** — 역시 합산 일치(1,390+10,900=12,290). 통과.
4. **SERP 문서수 2,841건·일치율 5/5** [근거: SERP] — 외부 재검증은 불가하나 출처가 명시돼 있고 다른 섹션(3절 빈틈 3가지)과 수치가 일관되게 재인용됨. 통과.
5. **쇼츠 1,689회·릴스 2,996회** [근거: 자사 성과기록] — 자사 1차 데이터로 외부 비교 불필요, 출처 명시. 통과.

무근거로 적힌 핵심 수치는 발견되지 않음. 다만 **2절 "정보형 70% + 거래형 30%"는 어떤 조회·계산에서 나온 비율인지 출처가 없음** — 이건 수치를 사실처럼 제시한 유일한 예외라 블로킹까지는 아니지만 아래 피드백에서 다룸.

## 2. 구조 검토

- 제목 후보(6절) ↔ 본문 범위(5절) ↔ 차별화 각도(4절)가 "도구 선택"이라는 한 질문으로 일관됨. 제목의 약속과 본문 내용 불일치 없음.
- **논리적 간극 1건**: 4절 차별화 근거("상위 5건 중 도구 제목 0건")는 `측백나무 전정` SERP에서 나온 결과인데, 1절에서 메인 키워드는 `전지가위`로 바뀌었다. 즉 **차별화 근거의 SERP와 실제 공략 키워드의 SERP가 다르다.** 브리프 스스로 이를 "미확인"으로 낮추고 조건부 지시를 걸어둔 점은 성실하지만, 이 간극이 완전히 해소된 것은 아니고 "집필 중 발견 시 재검토"로 넘어간 상태다. 블로킹은 아니나 작가가 반드시 인지해야 함.
- 검색 의도(2절)와 본문 순서(5절)가 "도구>시기·방법>원인>복구" 순으로 정확히 매칭됨. 의도 충족 설계 양호.
