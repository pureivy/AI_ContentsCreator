- 실측 검색량 API가 무응답이면 재시도만 반복하지 말고 SERP 문서수 같은 대체 경쟁도 지표로 즉시 전환한다

## 갱신 (2026-07-14)
- naver_searchad 검색량 API 무응답 시 SERP 문서수·상위 제목·유튜브 조회수로 즉시 전환해 경쟁도를 대체 산출한다

## 갱신 (2026-07-15)
- 검색광고 API 무응답 시 절대 검색량을 추정치로 채우지 말고 SERP 문서수·자동완성으로 대체 지표를 명시해 제출한다

## 갱신 (2026-07-15)
- 1차 데이터 소스(절대 검색량)가 무응답이면 즉시 대체 루틴(SERP 문서수·자동완성)으로 전환해 착수 지연을 없앤다.

## 갱신 (2026-07-15)
- 검색광고 API가 무응답이면 재시도 대신 즉시 SERP 문서수 기반 상대 경쟁도로 전환하고 절대수치 단정 표현을 금지 문구로 명시한다
