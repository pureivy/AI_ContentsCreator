# 콘텐츠 브리프 v2 — 「사과나무잎 변색 감별」

**작성:** 서다인(리서치·SEO 디렉터) | **개정일:** 2026-08-12(수) 라운드 1 반영판
**상태:** **착수 보류(BLOCKED)** — 검증팀 게이트 판정 수용. 아래 §8 G1·G2·G3 해소 전 집필 금지.
**변경 요약:** 검증 지적 S1~S10 전건 반영. 핵심 명제의 근거 사슬을 **끊긴 채로 주장하지 않고, 조건부 2트랙으로 분리**했다. 산림청 수치의 사용 범위를 축소하고, "8월 변색 = 비정상" 단정을 철회했다.

---

## §-1. 라운드 1 지적 처리 대장

| # | 지적 | 처리 | 반영 위치 |
|---|---|---|---|
| S1 | "절정=50% 착색" 원문 미확인 | **수용.** 50% 정의 **인용 금지 처리**, 발표일·URL 미표기 사실 명시, G1 게이트로 승격 | §0, §5-②, §6 |
| S2 | 절정일로 "8월=비정상" 도출 불가 | **수용.** 단정 철회 → "정상 노화 시기와는 거리가 있다"로 하향. 첫단풍 개시일 ⚠️ 데이터 없음 | §0, §5-② |
| S3 | 메인 수종 사과나무 근거 0건 | **수용.** 최우선 게이트 G2로 승격, 미확보 시 대체 설계(§6-B) 명문화 | §8, §6 |
| S4 | §0 단서 vs §6 도입 모순(등치) | **수용.** 도입 문안을 **대조 구조**로 지정 | §6 도입 |
| S5 | 원인명 봉쇄 시 실행 항목 0개 | **수용.** "원인명 없이 실행 가능한 행동" 목록을 사전 설계 | §6-B |
| S6 | 병반 축 누락 | **수용.** 감별 3갈래 → **4갈래**(병반 계열 신설) | §5-①, §6 |
| S7 | 경쟁 분석 축 ≠ 메인 키워드 축 | **수용.** 「사과나무잎」 SERP 조회 **권장→필수(G3)**. 「나무 잎 갈변」 SERP 근거의 적용 범위 제한 명시 | §3, §5-③, §8 |
| S8 | 의도 분류 근거 약함(모바일 90%) | **수용.** 모바일 90%를 의도 근거에서 **삭제**, 식별 의도 흡수 설계 추가 | §2 |
| S9 | 지역 기상 근거 없음 | **수용.** 수분·고온 축 1순위 배치 **철회**, 병해 축과 동등 병치. 기상 실측 ⚠️ 데이터 없음 | §5, §6 |
| S10 | 연관어 4건 누락·밀도 계산식·자수 | **부분 수용/부분 정정.** 연관어는 4건
