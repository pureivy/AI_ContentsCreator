팀원 두 명의 산출이 "사망 판정 → 재조회 예고"에서 멈춘 상태를 제가 이어받은 게 라운드1 산출물이었고, 정하람 검토관이 지적한 7건 중 치명 2건·중대 2건은 **집필 착수 게이트**로 격상해 반영했습니다. 다만 이번 라운드에 추가 실측 도구 결과는 확보하지 못했으므로, **미회수 항목을 추정으로 채우지 않고 게이트·이중트랙 구조로 처리**했습니다.

# 콘텐츠 브리프 v2 — 가을 잎 증상 자가진단 (리서치·SEO팀)

작성: 서다인(리서치·SEO 디렉터) / 2026-09-26 / 취합: 오세라(트렌드)·김도현(SEO) + 디렉터 직접 보강 실측
개정: v2 (정하람 라운드1 검토 반영)

## 변경 이력 (v1 → v2)

| 검토 지적 | 처리 |
|---|---|
| #1 메인 키워드 미실측 상태로 섹션표 확정 | **§5를 "조건부 초안"으로 격하 + §A 선행 게이트 신설.** 실측 전 작가 착수 금지 |
| #2 자가진단표 근거 0건 | **표를 행 단위 근거 슬롯 구조로 재작성.** 근거 미확보 행은 "의심" 단정 삭제 → 관찰 서술로 강제 다운톤 |
| #3 관엽식물(고무나무) 혼입 위험 | §5 금지사항 ④로 명시 추가 |
| #4 거적대기 2,060회 방법론 불투명 | **행 분리.** `거적대기` = 연관키워드 개별 행 볼륨(2,060), `나무 월동준비`(시드) 자체 볼륨은 ⚠️ 미회수로 분리 표기 |
| #5 단풍 9/15~11/20 출처 미표기 | 출처를 "팀 내부 이벤트 캘린더(외부 기관 자료 아님)"로 각주 명시 + 본문용 표현은 "9~11월 가을철"로 완화 |
| #6 표본 10건 단정형 서술 | §4 서두를 "확보한 표본 10건 기준으로는"으로 완화 |
| #7 문서수 560건 방법론 | 방법론 ⚠️ 미확인으로 고지 + "사실상 비어 있음" 표현 철회 |
