## §0. 라운드 1 지적 처리 대장 (먼저 읽을 것)

| 지적 | 심각도 | 처리 결과 |
|---|---|---|
| ① E3·E4 출처 URL 부재 | 상 | **처리안 (b) 채택 — E3·E4를 근거표에서 삭제.** §5 문구를 "독립 4출처 교차 일치" → **"완전 역추적 1건 + 부분 추적 1건"** 으로 하향. **R7을 "부분 해소" → "미해소"로 복구**(§7). E3·E4가 떠받치던 서술(휴면기 인과 설명, 상록수 적기)은 §5·S3에서 **단정 금지 항목으로 강등** |
| ② [IMAGE:] 슬롯 0건 | 상 | **§6에 2개 슬롯 확정 배치**(S1 도입 1 / S3 대비표 직전 1). 대체텍스트 지침 포함 |
| ③ 이모지·특수문자 금지 조항 부재 | 상 | **§6 공통 집필 규칙에 명시 조항 신설.** 대비표 가부는 "가능/불가/해당없음" 텍스트만. 브리프 본문에서도 장식 기호 사용을 최소화하여 본보기를 정정함 |
| ④ 경산 기온·물주기 수치 미제공 | 중 | 기상청 평년값을 **본 라운드에서 확보하지 못함(데이터 없음)** → **R4(수치 금지, 정성 서술만)에 편입.** 대비표에서 "물주기 빈도" 칸 삭제, "겨울 최저기온 대응"을 "겨울 찬바람·언 땅 노출 여부"로 정성 전환 |
| ⑤ 오염률 산술 오류 | 중 | 문장 정정 — **"비직결 3건(60%)으로 팀 표준선에 도달"**. 미분류 1건은 지어내지 않고 **R8(신규 미해소)** 로 등록. 강등 결론은 **"미분류 1건이 목본이더라도 직결 최대 40%"** 라는 산술로 재지지 |
| ⑥ 제목 자수 기준 | 중 | **자수 산정 기준 = 공백 포함**을 §8에 명시하고 3안 전부 재계산 |
| ⑦ 무검증 태그 | 중 | `정원나무심기` **삭제** → SERP 실측 근거가 있는 `정원수`로 교체(볼륨 미실측 사실 병기) |
| ⑧ 논거 혼합 | 하 | 유튜브 오염 근거를 **§2에서 삭제하고 §4(포맷 빈틈)로 이동** |
