| 지적 | 처리 |
|---|---|
| S-1 제목 A안이 자기 배제 원칙 위반 | **A안에서 '폭염' 삭제**, 태그 `폭염나무` → `나무잎마름원인`으로 교체. §3-2 배제 원칙은 완화 없이 유지 |
| S-2 §6-1 근거가 주장 미지지 | **키워드별로 근거 분리**, `폭염 나무 관리` 2/5 반영. 배제 주사유를 "실검색량 월 10 미만"으로 재정렬 |
| S-3 미확인 사항 단정 | 빈틈①을 **"제목 기준 관측"으로 하향**, 각도 A의 1차 근거를 **검색 의도(총칭 증상어 vs 병명어 분리 실측)**로 이전 |
| S-4 밀도 산식 재현 불가 | **산식 2종 명시 + 각 산식별 노출 횟수표 재산정**, 본문 분량 하한 2,300자로 상향 |
| S-5 제목 글자수 오기 | **공백 포함 기준 병기**(A안 29자·B안 35자) |
| 지적 A `나무 물주기` 문서수 | **조회 불가 — [결손] 유지**. 대신 메인 선정 근거를 의도 논리 + 교체 조건식으로 완결 |
| 지적 B 각도 조건부 의존 | **기록 부재 시 대체 골격(Plan B)을 §4-말에 사전 확정** |
| 지적 C n=1 표기 | 의도 ⑤ 근거를 "상위 1건 관측(n=1, 추정)"으로 하향 |
| 지적 D 데이터랩 이상치 | '여름' 5월 피크는 이상치 가능성 병기, **시의성 판정 가중 하향** |
| 지적 E 초가을 경계 | §6-5에 허용 범위 부기 |
| 지적 F·G·H 서식·합산규칙·중복 | 기호 치환, 각주 추가, 중복 3곳 → 참조 처리 |
