## 0. 라운드 1 지적 반영 대조표 (먼저 읽을 것)

| 지적 | 처리 | 위치 |
|---|---|---|
| S1 회양목 "국내 최다 식재 관목" 무근거 | **문장 삭제.** 선정 근거를 PC 비중 13.2% 실측 1건으로 교체 | §4 |
| S2 배롱나무 "7~9월 개화" 자기규칙 위반 | **"여름 개화 수종"으로 하향 통일.** 개화기 수치는 G3으로 일원화 | §4·§7 |
| S3 문서수 쿼리 미기록 | **문서수를 결론 근거에서 제외**, 참고 각주로 강등 | §2-1 각주 |
| S4 성과신호 정의 부재·색인 미확인 | **성과신호 지표 인용 삭제**(조회수만 인용). 내부 링크는 조건부 G8로 강등 | §3-4·§6 |
| S5 포포 "2품종 이상 구매" 무근거 | **문장 삭제.** 대체 항목은 "라벨 품종명 표기 확인"(절차 안내) | §5 |
| C1 분량 3중 충돌 | **(B)안 채택 — 상세 3종 + 요약 3종. 글자 기준 총 3,600~3,900자(정책 상한 4,000자 내)** | §5 |
| C2 KD-proxy 변별력 붕괴 | **지수 폐기.** 경쟁·볼륨 2열만 유지 | §2-2 |
| C3 7월 식재 안전 경고 누락 | **"지금 사면 심지 말고 보관" 블록 신설**(필수) | §5-3 |
| C4 G4 순서 역전 | **상품 연결 축을 선정 근거에서 제외 → 2축(볼륨·경쟁) 재판정.** 취급 품목 확인은 발행 선결 P1로 승격 | §4·§7 |
| C5 폐기 프레임의 첫 문단 배치 | **콘셉트 선언을 마무리 블록으로 이동.** 첫 문단은 메인 1회 + 독자 상황 1문장 | §6 |
| C6 밀도 기준 미정의 | **글자 기준으로 재산출**(메인 12~18회) | §6 |
| C7 소표본 % 본문 전이 | 표 헤더에 **"본문 인용 금지 · 작업 배분용"** 명시 | §3-1 |
| C8 문화 서술 무게이트 | **G6 신설**(출처 1건 없으면 삭제) + 문화 배분 25%→15% 하향
