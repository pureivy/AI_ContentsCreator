## §-1. 검토 반영 대조표 (무엇을 어떻게 고쳤는가)

| 지적 | 판정 | 조치 |
|---|---|---|
| SC-1 경쟁 글 본문 내용 단정 | **전면 수용** | §4·§5의 전체 부정어를 **"제목 층위 한정"**으로 강등. "전부 나열형에서 멈춘다" 삭제. 본문 열람 기록표는 미수행이므로 **⚠️ 데이터 없음** 표기 |
| SC-2 B2B 유출 낮음 | **전면 수용** | 해당 문장 **삭제**. 배분 근거를 SERP 제목 층위 공백으로 교체 |
| SC-3 8월 지수 부분 집계 | **수용** | 8월 값에 부분 집계 주석 부기. 판정(계절성 주장 금지)은 오히려 강화되어 유지 |
| SC-4 9,690 동일값 | **부분 수용** | 재조회 미수행 → **볼륨 확정 유보** 표기. 밀도 검산은 볼륨과 무관하므로 유지 |
| SC-5 볏짚+녹화마대 1,220 | **수용** | 개별 분해 불가 → **해당 수치 삭제**. 월동 축 근거를 「나무 월동준비」 경쟁 '낮음' + SERP 2011년 문서로 한정 |
| 결함① 폐기 키워드 SERP로 메인 판정 | **수용** | **차단 조건 C 신설**(「조경수」 SERP 일치율 확보 전 착수 금지) |
| 결함② S2 규격 항목 붕괴 | **수용** | 확인 경로 명시 + **폴백 재정의**(공적 규격 → 판매처 규격 표기 읽는 법) |
| 결함③ 초가을 식재 규칙 충돌 | **수용** | 한 줄 규칙으로 통일(§0-④) |
| 결함④ 사진 단일 실패점 | **수용** | **사진 폴백 표 구조** 명기 |
| 결함⑤ 태그 볼륨 미확인 | **부분 수용** | 추가 실측 미수행 → 태그를 **실측 확인 3개 + 문맥 태그** 로 계층 분리, 미확인은 ⚠️ 표기 |
