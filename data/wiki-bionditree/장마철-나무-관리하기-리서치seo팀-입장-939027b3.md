팩트체커 정하람 님 지적 9건 반영합니다. 특히 **결함 1(자동완성 개수 모순)**은 근거 신뢰를 흔드는 치명 지적이라 최우선 정정합니다. 새 조회 없이 지어내지 않고, 미확인 항목은 ⚠️로 강등해 정직 표기합니다.

**정정 요지 (선반영 공개):**
- [결함 1] 실측 로그를 재확인한 결과 재배성 파생어는 **곰팡이·물주기·키우는법 3개**입니다. "4개"는 표기 오류 → **3개로 정정**. (원 로그에 4번째 재배성 파생어 없음)
- [결함 3] 2026년 장마 실황/종료 발표는 **이번 턴 미조회 → ⚠️ 데이터 없음**. 게이트를 "평년값 통과"에서 "조건부 통과"로 강등, 발행 직전 실황 1회 조회를 필수 게이트로 승격.
- [결함 2] 도메인 분포 미측정 → "대형매체 독점 아님" 문구 **삭제**.
- [결함 7] 브랜드 컨텍스트상 확인 품목은 **모종·묘목뿐**. 상토·살균제 취급 미확인 → 제품 연결을 **모종·묘목으로 한정**, 자재는 "확인 후 연결" 조건부.

## 0. 시의성 게이트 판정 (조건부 통과 — 실황 미확정)
- **이벤트 달력**: 여름 성수기(6/1~8/31) 구간 내 ✅ [근거: 시의성 게이트 이벤트 달력]
- **계절 키워드**: 현재 여름(6~8월), '장마철' 정합 ✅
- **⚠️ 실황 미확정**: 2026년 실제 장마 종료 발표는 **이번 턴 미조회 — 데이터 없음**. 7월 하순은 장마 종료 겹침 구간이라 두 시나리오 모두 대비:
  - (A) 장마 진행 중 → 현 프레이밍 유지("장마철 관리")
  - (B) 이미 종료 → 제목·도입을 **"장마 직후·한여름 과습 회복"**으로 즉시 전환(키워드·구조 재사용 가능)
- **필수 후속**: 발행 직전 기상청 장마 실황/종료 발표 **1회 조회 → 게이트 실측 확정**. 미조회 시 발행 보류.
