# 콘텐츠 브리프 (R2 갱신판) — 살구나무 vs 매실나무, "우리 마당엔 뭘 심을까" 결정 가이드

작성: 서다인(리서치·SEO 디렉터) / 최초 2026-09-25 / R1 반영 2026-09-25 / **R2 반영(검증 반려 해소) 2026-09-25**
채널: 네이버 블로그(메인) + 카드뉴스 파생 1건

**R1에서 바뀐 것(정하람 검토 반영)**
| # | 지적 | 처리 |
|---|---|---|
| ① | 비교표 1·2순위 수치 미확보인데 발행 계획만 확정 | 비교표를 "수치형 → 판단·확인행동형"으로 전면 교체(10장) + 수치 확보 요청서·마감·자동 대체경로 명문화(11장) |
| ② | "실질 경쟁 낮음"은 비약 | "의도 공백 확인 / 순위 진입 가능성은 미검증"으로 수정, 진입 리스크 별도 기재(3장) |
| ③ | "성과신호" 정의 없음 | 정의 ⚠️ 미확인으로 격하, 근거 사용 중단(1장 각주①) |
| ④ | 블루베리묘목 내부링크 맥락 없음 | 「단풍나무묘목 9월 구입, 11월 심기까지 확인할 것」으로 교체 |
| ⑤ | 개화·열매 아카이브 실재 미확인 | ⚠️ 미확인 표기 + 디폴트 "미사용"(7장) |
| ⑥ | (자체) 타 팀과 중복 | 촬영 기획을 "캡션이 담을 판단 정보"만 남기고 연출·구도는 촬영/디자인팀 위임(7장) |

**R2에서 바뀐 것(검증 반려 4건 해소)**
| # | 지적 | 처리 |
|---|---|---|
| ⓐ | 농장에 살구·매실 **성목 보유 여부 미확인**인데 여러 섹션이 그 전제 위에 설계됨 | **"자사 성목 실측"을 디폴트에서 제거.** 6장 2번 섹션은 수치 없는 *자리 잡는 방법* 서술로 재설계, 10장 표 ②칸은 **디폴트 = 수치 칸 비움**, 7장 컷3은 **디폴트 미사용 + 대체 컷 지정**, 11장은 **11-0 보유 여부 선행 확인**을 통과해야만 실측 요청서가 발동하도록 변경 |
| ⓑ | 10장 ④칸 "자사 영상 수요가 살구보다 큼(도달 3,834 vs 1,232)" = 도달→수요 인과 비약 | **인과 표현 전면 삭제.** 표에서 수치·비교 문구 제거, 1장에는 관측치로만 남기고 "수요 크기 비교 근거로 쓰지 말 것" 명시 |
| ⓒ | 5장 5순위 "수확 시기와 그때 할 일"이 6장 섹션에 자리 없음 | **6장 3번 섹션 말미 2~3줄로 배정**(섹션명도 "열매를 어디에, 언제 쓸 건가"로 조정) |
| ⓓ | 5장
