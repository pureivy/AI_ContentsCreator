|---|---|

| S-3 kPa 적용범위 위반 | 화분 블루베리 **한정 참고값**으로 격하. 지면 식재 판별의 주 기준은 **관찰 절차**로 재정의. 타 수종 확장 금지 명문화 |
| S-4 "3개월 연속 하락" | "6월 피크 이후 **2개월 연속 하락**, 8월은 피크 대비 42%"로 수정 |
| S-5 "1/959" | **삭제.** 방향성 주장만 유지 |
| C-1 제목-집필금지 충돌 | **(b) 채택 — 권장안을 B로 교체.** A안은 공식 병징 근거 확보 시에만 승격 |
| C-2 선언-목차 불일치 | 전반부 **배제 진단 파트 50% 이상**, 원인별 대응은 4~6문장 요약. 4단 대칭 고정 해제 |
| C-3 표본 10 과대해석 | 모바일 편중 근거를 **"편집 판단"**으로 강등, 실측 근거 표기 제거 |
| C-4 미검증 키워드 메인 | **시나리오 B(블루베리나무 메인) 병기 + 분기 조건 1줄** |
| C-5~C-8 | 카운팅 규칙·목표 분량·IMAGE 슬롯 3개소·이모지 0 정책 명문화 |
