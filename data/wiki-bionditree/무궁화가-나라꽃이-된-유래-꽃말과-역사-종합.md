## 팀 토론 종합 — 무궁화 나라꽃 콘텐츠 검증

**① 합의·검증된 것**

[[무궁화키우기]]가 메인 SEO 승부처로 확정됨(실검색량 90회, PC/모바일 비율 근거 명시). 무궁화 실취급 가능 여부는 데이터 미확보로 기각되었으나, 이를 피하기 위해 "정보형 고르는 법" 기본 프레임을 도입하고 취급 확인 시에만 실무 프레임으로 분기하는 조건부 운영 방식으로 합의됨. SERP 상위 10건에서 재배·관리 정보 의도 불일치 실측(표 제시)으로 공급 공백이 검증되어 차별 포지션 근거 확보. 직전 반려 2건(개화 시기 무근거 단정 삭제, 메인 키워드 제목 미반영) 모두 해소되었고 스팟체크 5건 통과.

**② 반박·기각된 주장**

"무궁화는 9월이 개화 말기"는 산림청·국립산림품종관리센터 출처 미확보로 근거 없는 사실 단정으로 판정, 삭제됨(추정으로 메우지 않음). "무궁화 33,320회"는 포괄어·오염 의심으로 메인 키워드에서 강등. [[무궁화]]의 실취급 확인 불가능성은 "판정·구매 실무" 프레임의 기본값 상향을 차단함.

**③ 열린 질문**

네이버 형태소 매칭 효과에서 붙여쓰기("무궁화키우기") 대 띄어쓰기 혼용의 실제 성능 검증이 브리프 단계 한계로 미뤄짐. A-3 제목의 자연스러움 다듬기 기준이 명문화되지 않음.
