## §-1. 라운드 1 지적 처리 결과 (변경 이력)

| 지적 | 처리 | 결과 |
|---|---|---|
| **SC-3 / R-1** 제목이 단정한 인과("자르면 꽃눈이 들어온다") 근거 0건 | 하계 전정·차광↔꽃눈 분화 공식 자료 **이번 라운드 확보 실패** → 추정으로 채우지 않음 | **제목 A안 폐기 확정.** 인과 단정을 뺀 판단·구별형으로 교체(§6). 본문에서도 해당 인과 **서술 금지 목록**에 등재(§4-2) |
| **SC-2 / R-2** E1·E2의 동계/하계 맥락 미확인 | 원문상 작업 시기 명시 여부 **⚠️ 미확인**. 확인 전 사용 범위를 축소 | E1·E2는 **"전정 일반의 과다 제거 위험 / 꽃눈 상태 확인 후 판단"** 근거로만 사용. **"8월 도장지 제거의 근거"로 제시 금지**(§4-1) |
| **SC-1** E1 연도 앵커 누락 | 보도자료 발표 연도·조사 시점 **⚠️ 미확인** | **53%·78% 수치는 연도 확인 전까지 본문 인용 금지.** E1은 인용구의 취지("각 과수원 꽃눈 분화율을 확인한 뒤 가지치기할 것")만 사용. H2#4 주장을 "품종별로 강도를 달리하라"→**"내 나무를 직접 확인하라"**로 교체 |
| **SC-4** 결과습성 3건 무출처 | 출처 확보 실패 | **해당 3문장 원고에서 삭제 지시**(§4-2). H2#4는 '목적 축(열매/수형)'과 관찰 기준으로 재구성 |
| **SC-5** SERP 쿼리명 불일치 | 수집 쿼리를 **`도장지` 단일**로 통일 | §2·§3 표기 일치화 |
| **R-3** H2#3 판단표 실행 기준 공백 | 수치 대신 **관찰 가능한 식별 기준 5축**으로 채움 | H2#1 식별 어휘와 동일 용어로 연결(§5) |
| **R-4** `여름전정` 태그 자기규칙 위반 / 신규 태그 2개 무근거 | **§1 규칙 갱신**(사유 명기) + 무근거 태그 2개 삭제 | 태그 5개로 축소(§6) |
