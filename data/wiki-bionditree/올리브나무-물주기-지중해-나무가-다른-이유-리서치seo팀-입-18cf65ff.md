## 0-A. 라운드 1 지적 처리 대장 (선두 배치 — 정정 내역 추적용)

| 지적 | 처리 | 위치 |
|---|---|---|
| S-1 SERP 5/5 오류 | **정정 → 4/5**. 40% 배분은 재산정해 **45%로 갱신**(L-2와 통합 처리) | §2 |
| S-2 보조1 산술 모순 | **표기 철회 → "합계 10회 수준(PC·모바일 원값 재조회 필요)"**. 판정 근거를 볼륨 단독에서 **볼륨+메인 대비 비율(680 대 10 수준)**로 이중화 | §1 |
| S-3 "연중 최저" 표본 초과 | **"관측 구간(26-02~08) 내 최저"로 축소**. 12개월 재조회를 최우선 과제로 등록 + **재조회 결과별 분기 시나리오 사전 확정** | §0-B, §7 |
| S-4 인과 서사 비약 | **"구매→실패→검색" 인과 삭제**. "3~4월이 공통 정점 구간"이라는 사실 서술만 존치 + 정규화 한계 명시 | §1 |
| S-5 유튜브 조회수 근거 역전 | **S4 근거를 자동완성 `과습` + SERP 1위 "잎 떨어짐" 진입으로 교체**. 조회수는 근거에서 삭제 | §3, §5 |
| S-6 "색인 성숙" 무근거 | **논거 삭제**. 발행 판정을 "저점기 자산 선점" 단일 논거로 축소 + 자사 색인 실측 부재를 명시 | §0-B |
| L-1 분량 자기 상한 초과 | 전체 분량 **2,000~2,600자(권장 2,300)**로 상향, 표 텍스트 포함 여부 명시 | §5 |
| L-2 의도 배분 불일치 | §2 배분표를 §5 실배분에 맞춰 **재산정(①45 / ②13 / ③+④33 / 리드·마무리9)**, 실외·노지 비중 확대 | §2, §5 |
| L-3 제목 약속 불이행 | **권장 제목을 ⓑ안(판단법)으로 교체**. 기관 자료 확보 시에만 "간격·기준" 제목 복귀 허용 | §6 |
