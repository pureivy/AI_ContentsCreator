## 0. 갱신 이력 (비평·반려 대응 요약)

| 비평 | 처리 | 반영 위치 |
|---|---|---|
| 1. §3에 근거 없는 "효능 쏠림" | **삭제·정정.** `블루베리묘목` 기준 SERP는 **미조사** → ⚠️ 데이터 없음으로 명시. 경쟁 유형 주장은 "좁은 마당에 블루베리" 표본 한정으로 범위 축소 | §2 메인 선정 근거 / §4 |
| 2. §3(조건부)과 §4(단정) 결론 충돌 | **각도 3을 섹션 C에 종속된 보조 결론으로 재배치.** 적용 범위를 "6축에서 어느 쪽도 뚜렷하지 않거나 처음 심는 경우"로 한정 | §5 각도 3 / §6 섹션 D |
| 3. "상위 5건" vs 표 4행 | **표를 5행으로 분리**(기존 3행에 2건이 묶여 있었음) → 글 수 5건과 일치 | §4 |
| 4. `블루베리효능` 지침 3곳 불일치 | **"태그·본문 어디에도 넣지 않는다"로 통일** | §2 보조표 / §7 태그 / §8 금칙 6 |
| 5. "유일하게 구매 전 탐색 의도" 과장 | **"블루베리 나무 자체를 사려는 의도"로 문구 정밀화.** 대형화분·화분받침대는 범용 원예 자재 의도로 구분 표기 | §2 메인 선정 근거 |
| 6. 물빠짐 영상 수치가 간접 신호 | **작가 가이드에 "블루베리 전용 통계 아님"을 톤에 드러낼 것 명시** | §5 근거 자료 1 / §6 섹션 B·E |
| 7. 데이터랩 두 비교 혼재 | **①올해 추이 / ②전년 비교로 불릿 분리** | §1 수요 추이 |
| **8. 보조키워드 `부직포` 본문 자리 미지정** | **보조 키워드 목록에서 제외.** §6 섹션 A~E의 어느 내용 항목에도 부직포를 다루는 자리가 없다(자재 세부·금액 서술을 금칙 4로 막아 둔 구조). 자리를 만들어 끼우는 대신 제외하고 사유를 근거와 함께 남김 | §2 보조표 / §2 제외 키워드 / §9 |
| **9. §4 표에 자사/타사 구분 없음** | **표에 「자사/타사」 열 추가.** #1은 자사 글로 확정 표기(근거: §5 각도 4의 자기잠식 판단 근거), 나머지
