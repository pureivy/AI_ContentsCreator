## 0. 라운드 1 지적 처리 내역 (선반영 요약)

| 지적 | 처리 |
|---|---|
| ❶ 간벌 오독 | **주장 철회.** R2 '간벌' 항목의 정의문·전후 맥락을 재확인하지 못했으므로 "9월 작업=간벌 계열" 서술을 **전면 삭제**. §4-2·H2-1 근거를 "정규 전정은 겨울(휴면기)"이라는 **단일 명제로 축소**. 간벌 관련 서술은 **본문 기재 금지** 목록에 등재(§4-3) |
| ❷ "가지 수 축소" 처방 | **근거 표기 분리 + 처방부 삭제.** 재식거리 수치만 출처 병기, 처방 문장 제거 |
| ❸ 재식거리 개념 혼동 | "다 자란 나무 심는 거리" → **"재식거리(주간×열간)"** 로 문구 교정 |
| ❹ R1 서지 불충분 | 조회일 병기 + **URL·페이지 제목 미기록을 결손으로 공개(§9-5).** 재조회 전까지 **직접 인용 대신 요지 서술** 등급으로 하향 |
| ❺ 조회 시점 누락 / 데이터랩 단정 | 전 수치에 "2026-08-24 조회 기준" 병기. **"연중 저점" 단정 철회**, 시의성 근거를 시점 정합성으로 대체 |
| 모순 (가)(나)(다) | 제목 대안 C 채택 / 도입 품종 분기형으로 교체 / 태그 `포도나무순치기` 제외 |
| 누락 — 발행 규격 | §10 신설(이미지 슬롯·이모지 0·문장 40자·문단 2~4문장·표 1개 이상) |
| SEO 계량 오류 | 메인 등장 지점 **4곳 명시**로 배치표 수정, 검산 재산출 |
