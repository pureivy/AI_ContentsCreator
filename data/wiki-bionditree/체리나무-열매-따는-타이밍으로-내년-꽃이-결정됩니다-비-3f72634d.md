## 1. 사실 스팟체크

검증할 본문 자체가 없습니다. 제출된 "산출물"은 작업 디렉터리를 탐색하는 Bash 명령 실행 기록(`ls -la`, `ls -R`, `wc`, `cat wiki.json` 등)뿐이며, 그 결과로 돌아온 내용은 빈 디렉터리 구조(`.claude/wiki/wiki.json` 경로 하나)와 공백 출력뿐입니다. 포포나무 관련 키워드 데이터, SERP 분석, 경쟁 콘텐츠 분석, 데이터랩 수치, 장르축 판정 등 직전 반려 지적 6건에 대응하는 실제 리서치 결과물이 단 한 줄도 제시되지 않았습니다.

따라서 "근거를 역추적"할 대상 자체가 존재하지 않습니다. 사실 스팟체크 통과 여부를 논할 수 없는 단계이며, 이는 곧 전체 반려 사유입니다.

## 2. 구조 검토 / 3. 린트 / 4. 채점표

리서치 보고서로서 갖춰야 할 최소 구성(메인/보조 키워드, 검색의도 분류, 경쟁 콘텐츠 비교표, 수요추이, 장르축 판정, 차별화 각도)이 전부 결손 상태입니다. 7개 기준 점수표를 형식상 남깁니다.

| 기준 | 점수 | 근거 |
|---|---|---|
| ①정확성 | 0/10 | 검증 가능한 주장·수치가 전혀 제출되지 않음 |
| ②실용성 | 0/10 | 집필에 쓸 구체적 리서치 데이터 없음 |
| ③논리 | 0/10 | 지적 6건 중 단 1건도 응답 내용 없음 |
| ④가독성 | 0/10 | 평가 대상 텍스트 없음(명령 실행 로그만 존재) |
| ⑤차별성 | 0/10 | 차별화 각도 미확정 상태 그대로, 경쟁 분석 없음 |
| ⑥SEO | 0/10 | 메인/보조 키워드 실측치 없음 |
| ⑦서식·발행 준비도 | 0/10 | 리서치 문서 형식 자체가 없음 |
| 합계 | 0/70 | 전원 미해소 |

## 판정 근거

직전 반려 지적 6건 — 장르축 확정, 보조 키워드 실측, 검색의도 분류, 경쟁 콘텐츠 3건 분석, 수요추이 데이터, 차별화 각도 확정 — 중 단 1건도 해소되지 않았습니다. 제출물은 작업 디렉터리에 리서치 자료가 있는지 "찾아보는" 행위 로그일 뿐, 찾은 결과(빈 폴더)에서 멈췄습니다. 리서치·SEO팀이 실제로 데이터랩·검색 결과·경쟁사 블로그를 확인한 산출물을 제출해야 합니다.

## 미해소

- 포포나무를 비온디트리가 "판매 품종(고르는 기준) 축"으로 다룰지, "우리가 팔지 않는 나무 알아보기 축"으로 다룰지 기획팀이 먼저 판정하고 그 판정 근거를 문서로 남겨야 한다. 비온디트리가 포포나무 묘목을 실제 취급하는지 여부를 농장 제품 목록 기준으로 먼저 확인할 것.
- 포포나무 메인 키워드 외에 보조 키워드 3~5개를 선정하고 각각의 월간 검색량과 경쟁도(네이버 데이터랩 또는 검색광고 키워드도구 수치)를 실측해 제출할 것.
- 포포나무를 검색했을 때 SERP 1~10위 콘텐츠의 유형(정보성/거래성/탐색성)을 직접 확인해 검색 의도를 분류하고, 어떤 유형이 우세한지 근거와 함께 밝힐 것.
- 포포나무 관련 경쟁 콘텐츠 최소 3건을 선정해 각각
