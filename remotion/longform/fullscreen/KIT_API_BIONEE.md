# 진행자 비온이(LONGFORM_PRESENTER 가 켜진 편만 — 장면 키트 문서 뒤에 붙는다)

화분 마스코트 비온이(연필 선화 화분 + 떡잎 귀 + 둥근 손 + 장화)가 화면 왼쪽 아래(자막 띠 위)에 서서 낭독에 맞춰 말하고(입은 소리로 자동) 몸짓한다.
장면은 화면 전체를 그리되 그 자리에 주인공을 두지 않고, 문장마다 비온이가 무엇을 할지 **신호(bioneeCues)** 로 고른다.

## 자리(꼭 지킨다)
- 장면은 **화면 전체**(1920×1080)를 그대로 쓴다. 비온이(키 약 330px)는 그 위에 얹히는 덮개 층으로 왼쪽 아래(발 = 자막 띠 바로 위)에 선다.
- 왼쪽 아래 **x < 420, y > 560**(무대 좌표)에는 **주인공 그림·라벨·끼움 카드를 두지 않는다**(비온이에 가린다). 종이·땅 선·땅 단면·풀·흙·하늘 같은 **배경은 그 아래로 끝까지 이어 그린다**(왼쪽만 비우지 않는다).
- 신호 좌표(target)는 장면 무대 좌표 그대로다.

## 신호 쓰는 법
장면 파일 맨 아래에 리터럴 배열 하나를 내보낸다(기본 내보내기와 따로):
```tsx
export const bioneeCues = [
  { at: 0.4, dur: 1.8, action: 'point', params: { target: { x: 1400, y: 420 } } },
  { at: 2.6, dur: 2.0, action: 'holdSign', params: { text: '잎이 진 뒤' } },
];
```
- `at`·`dur` = 초(이 문장 시작 기준). job.json 의 `words[].start`(낱말을 말하는 시각, 초)를 보고 그 낱말에 맞춘다. `dur` 생략 = 기본 길이.
- **문장마다 0~3개.** 가만히 둘 문장은 `export const bioneeCues = [];`(빈 배열 = 일부러 가만히 — 숨쉬기·깜빡임·두리번은 저절로 돈다). 내보내지 않으면 시스템이 자동으로 고른다.
- **리터럴만**: 숫자·글자·{ }·[ ] 그대로. 변수·계산식·함수(atFromWords 등) 금지 — 렌더 전에 글로 읽는다. 못 읽으면 ./check.sh 가 문제로 알려 준다.
- 신호끼리 겹쳐도 된다 — 동작마다 쥐는 부위(팔·얼굴·몸·효과)만 바꾼다. 예) `laugh` 와 `thumbsUp` 을 같은 at 에 = 웃으며 엄지.

## 동작(기본 길이 초)
| action | 뜻 | params |
|---|---|---|
| point (2.0) | 그 그림을 손가락으로 가리킴(눈도 그쪽) | `target` = 가리킬 그림의 무대 좌표 `{ x, y }` |
| lookAt (1.5) | 눈·몸만 그쪽으로 | `target` |
| holdSign (2.5) | 팻말 들기 | `text` **6자 이내, 이 문장에 나온 낱말만**(공백 포함 6자) |
| hold (2.0) | 소품 들기 | `prop` 'magnifier'(돋보기)·'can'(물뿌리개)·'stick'(지시봉) |
| surprised (1.2) | 놀람 — 큰 눈·두 손 볼에·느낌표 | — |
| worried (1.6) | 걱정 — 八 눈썹·물결 입·귀 처짐·땀 | — |
| think (2.0) | 턱 괴고 생각, 물음표 | `hand` 'L'·'R' |
| thumbsUp (1.4) | 엄지 척·반짝 | `hand`, `expr` |
| nod (0.9) | 끄덕끄덕 | `times` |
| shake (1.0) | 도리도리(아니에요) | `times` |
| laugh (1.4) | 크게 웃음 | — |
| hop (0.7) | 깡충 | `times` |
| wave (1.6) | 손 흔들기·웃음 | `hand` |
| walkTo (1.5) | 비운 자리 안에서 옆으로 몇 걸음 | `x`(무대 px, 비운 자리 안으로 잘린다) |
| turn (0.5) | 돌아섬(끝난 뒤에도 유지) | `to` -1(왼 옆)…0(정면)…1(오 옆) 또는 'left'·'right'·'front' |
| face (1.5) | 표정만 | `expr` |
| walkIn (2.0) | 걸어 들어옴 — **편 첫 문장에만**(그 밖은 무시) | — |
| bow (1.2) | 꾸벅 인사 | — |
| walkOut (1.8) | 걸어 나감 — **편 마지막 문장에만**(그 밖은 무시) | — |

공통 params: `strength`(0.3~1.5), `expr`(표정 덮어쓰기: neutral·calm·happy·grin·laugh·surprised·worried·angry·thinking·sleepy·playful·sad·shy·focused).

## 고르는 요령 — 문장의 뜻으로
- 문장이 그림 속 무엇을 말하면 **그 그림을 `point`**(target = 그 부품의 무대 좌표 — 나무면 줄기·잎 쪽, 라벨이면 라벨 자리). 그 낱말을 말하는 시각에 맞춘다.
- 경고(안 됩니다·주의·죽어요·위험) → `surprised` 또는 `worried`. 질문·"왜일까요" → `think`. 요령·정답·"이러면 됩니다" → `thumbsUp` 또는 `nod`. 아니라는 말 → `shake`.
- 핵심 낱말 하나를 못 박고 싶으면 `holdSign`(문장에 나온 말 그대로, 6자 이내). 장면 라벨과 같은 말을 또 들 필요는 없다.
- 같은 동작을 이웃 문장에서 연달아 쓰지 않는다. 한 문장에 큰 동작(걷기·깡충·팻말)은 하나만. 가만히 두는 문장도 있어야 자연스럽다.
- 편 첫 문장: `walkIn` 다음 `wave`. 편 마지막 문장: `bow` 다음 `walkOut`(빠뜨리면 시스템이 걸어 들어오기·나가기를 채운다). 장 제목 카드 동안의 몸짓도 시스템이 넣는다.
