# 진행자 비온이(LONGFORM_PRESENTER 가 켜진 편만 — 장면 키트 문서 뒤에 붙는다)

화분 마스코트 비온이가 왼쪽 아래(자막 띠 위)에 서서 낭독에 맞춰 말하고 몸짓한다. 장면은 그 자리를 비워 둔다.

## 자리
- **진행자 비온이가 켜진 편(LONGFORM_PRESENTER)**: 왼쪽 아래 presenter 자리(**x<420, y>620**)는 비워 두기 — 비온이(화분 마스코트)가 서서 말하는 자리다. 땅 선·땅 단면은 x 440 부터.

## 진행자 비온이 신호(선택)
- 기본은 자동이다: 편 첫 문장 = 손 흔들기, 마지막 = 인사(절), 경고 말(안 됩니다·금지·주의·위험·죽) = 놀람, 강조 박자(처음 `hi` 라벨의 `atFromWords` 낱말) = 그쪽 가리키기, 요령·정리 말 = 두 손 모음, 그 밖 = 가만히.
- 장면이 바꾸고 싶으면 파일에서 내보낸다(초 단위, 세그먼트 시작 기준):
```tsx
export const presenterCue = { pose: 'point', target: 'right', at: 1.4, until: 3.2 };
// pose: 'idle' | 'wave' | 'point' | 'clasp' | 'surprised' | 'bow',  target(point 만): 'left' | 'right' | 'up'
```
- 객체 리터럴 그대로(계산식·변수 금지 — 렌더 전에 글로 읽는다).
