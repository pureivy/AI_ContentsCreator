# 유튜브 조회수 급감 원인 분석 (2026-09-04)

사용자 가설: "며칠 전 파일 경로 설정을 다시 한 뒤 유튜브·인스타 조회수가 급감했다.
그때 오류가 생긴 것 아닌가."

**결론: 파일 경로 변경(2026-08-31 `6ddeed2`)이 원인이라는 증거는 없다.** 그 커밋이 만든
산출물은 변경 전후가 동일하고, 유튜브가 받은 파일도 정상이다. 문제는 유튜브 쇼츠 피드
노출이 끊긴 것이고, 검색 유입과 인스타는 그대로다 — 파일 문제라면 그럴 수가 없다.

## 1. 급감은 실재한다 (연령 보정 후)

조회수는 누적이라 업로드 후 경과 시간을 맞춰야 비교가 된다. 업로드 30시간 이내 조회수:

| 업로드일 | 편수 | 중앙값 | 개별 값 |
|---|---|---|---|
| 08-29 | 3 | 1,100 | 748 / 1,100 / 1,146 |
| 08-30 | 3 | 1,166 | 1,109 / 1,166 / 1,234 |
| 08-31 | 2 | 1,085 | 1,071 / 1,099 |
| 09-01 | 2 | 1,074 | 1,051 / 1,097 |
| **09-02** | 2 | 581 | **14** / 1,148 |
| **09-03** | 3 | **12** | 6 / 12 / 33 |
| **09-04** | 1 | **4** | 4 |

09-02 오후 업로드분부터 끊겼다. 09-03 이후는 전부 두 자리 이하.

## 2. 업로드된 파일은 정상이다 (파일 경로 가설 반증)

유튜브 Data API 로 실제 업로드본을 조회했다(최근 20편):

| 항목 | 결과 |
|---|---|
| 공개 상태 | 전부 `public` |
| 처리 상태 | 전부 `processed` |
| 해상도 | 전부 1080×1920 |
| 비트레이트 | 787k ~ 2,358k (변경 전후 같은 범위) |
| 길이 | PT31S ~ PT41S (쇼츠 자격 충족) |
| `#Shorts` | 전부 포함 |
| 태그·설명·라이선스·임베드 | 변경 전후 동일 |

09-01 이전 편과 09-02 이후 편 사이에 **구별되는 차이가 없다.**

### 정리 로직이 업로드본을 건드릴 수 없는 이유

`shouldArchiveShortsVideo` 는 **유튜브와 메타가 둘 다 발행 확인된 뒤에만** true 다.

```ts
const yt = !!(s.youtubeId ?? '').trim();
const meta = !!(s.igReelId ?? '').trim() || !!(s.metaPublishedTs ?? '').trim();
return yt && meta;
```

즉 원본이 프록시로 교체되는 시점에는 두 채널 업로드가 이미 끝나 있다. 그리고 위 표의
비트레이트가 저용량 프록시가 아니라 원본 수준임을 실측으로 확인했다.

## 3. 끊긴 것은 '쇼츠 피드' 한 곳이다

유튜브 애널리틱스 유입 경로(집계가 도달한 09-01까지):

| 날짜 | 쇼츠 피드 | 검색 | 구독자 | 채널 |
|---|---|---|---|---|
| 08-27 | 3,539 | 320 | 72 | 57 |
| 08-28 | 2,832 | 264 | 52 | 31 |
| 08-29 | 3,477 | 340 | 68 | 52 |
| 08-30 | 3,136 | 254 | 69 | – |
| 08-31 | **2,201** | 230 | 66 | 51 |
| 09-01 | **1,329** | 198 | 55 | 14 |

**검색 유입은 198~340 으로 내내 평평하다.** 줄어든 것은 쇼츠 피드뿐이고, 08-30 을 정점으로
사흘에 걸쳐 3,136 → 2,201 → 1,329 로 계단식으로 빠졌다.

> 애널리틱스는 09-01 까지만 집계돼 있다(오늘 09-04). 09-02 이후 공백은 유튜브의 집계
> 지연이지 0 이 아니다 — 실시간 Data API 는 4·6·12·33 회를 반환한다.

## 4. 인스타는 같이 무너지지 않았다

업로드 30시간 이내 릴스 조회수 중앙값:

```
08-27  304      08-31  448      09-02  541
08-28  1,896    09-01  500      09-03  356
08-29  543                      09-04  129 (n=2)
08-30  1,231
```

09-03 의 356 은 08-27 의 304 과 같은 범위다. 인스타는 **약세이지 붕괴가 아니다.**
파일 파이프라인이 깨졌다면 두 채널이 같은 모양으로 무너졌어야 한다.

## 4-b. 지속률은 멀쩡했다 — '이탈'이 아니라 '노출 끊김'

성과 탭에 붙인 애널리틱스 값(집계가 도달한 편만):

| 업로드 | 조회 | 지속률 | 쇼츠 피드 비중 |
|---|---|---|---|
| 09-01 | 1,118 | 69% | **98%** |
| 09-01 | 1,099 | 74% | **97%** |
| 08-31 | 1,051 | 62% | **98%** |
| 08-31 | 1,128 | 75% | **93%** |
| 08-30 | 1,125 | 185% | **97%** |
| 08-29 | 1,249 | 112% | **95%** |

두 가지가 읽힌다.

1. **지속률 55~185%** — 사람들이 보다가 나간 게 아니다. 100%를 넘는 편은 반복 재생이다.
   콘텐츠가 갑자기 나빠져서 이탈한 것이라면 이 값이 먼저 떨어졌어야 한다.
2. **피드 비중 93~98%** — 이 채널 조회는 사실상 전부 쇼츠 피드에서 왔다. 검색은 2~7%뿐이다.
   그래서 피드가 끊기면 남는 게 한 자릿수~수십 회다. 실제로 09-02 이후가 정확히 그 값이다.

## 5. 무너지기 전의 수치 자체가 이상했다

08-22 ~ 09-01 의 편별 24시간 조회수를 보면 993, 1,025, 1,025, 976, 1,026, 855, 1,108,
1,029, 1,100, 1,166, 1,085, 1,074 — **40편 가까이가 1,000~1,200 에 몰려 있다.**

자연 노출은 꼬리가 길다. 어떤 편은 300, 어떤 편은 10,000 이 나온다. 이렇게 좁은 띠에
모이는 것은 고정된 노출 할당량이 배분되다 끊긴 모양에 가깝다.
(관련: 메모리 `shorts-flat-distribution-diagnosis`)

## 판정

| 가설 | 판정 | 근거 |
|---|---|---|
| 파일 경로/정리 변경이 업로드를 망가뜨렸다 | **기각** | 업로드본 해상도·비트레이트·길이·공개상태·태그가 변경 전후 동일. 정리는 양 채널 발행 확인 뒤에만 동작 |
| 업로드 실패·비공개 방치 | **기각** | 전부 `public` + `processed` |
| 쇼츠 자격 상실(세로·길이·태그) | **기각** | 1080×1920 · 31~41초 · `#Shorts` 포함 |
| 계정/영상 단위 문제 | **기각에 가까움** | 검색 유입은 평평. 채널 자체가 막혔다면 검색도 줄어야 한다 |
| 쇼츠 추천 피드가 이 채널 배분을 거둬들였다 | **남는 설명** | 피드 유입만 사흘에 걸쳐 계단식 감소, 검색 무영향, 인스타 무관 |

시점도 맞지 않는다. 파일 경로 커밋은 08-31 15:06 인데, 피드 감소는 **08-30 부터** 이미
시작됐고 하루 만에 꺾인 게 아니라 사흘에 걸쳐 진행됐다. 한 번의 코드 변경이 만드는
모양이 아니다.

## 이 분석이 말하지 못하는 것

- 쇼츠 피드가 왜 배분을 거뒀는지는 유튜브만 안다. 정책 위반 통지가 있었는지는 API 로
  확인할 수 없다 — **유튜브 스튜디오 > 설정 > 채널 > 기능 사용 자격**과 알림함을 직접
  확인해야 한다.
- 09-02 이후의 유입 경로 breakdown 은 집계 지연으로 아직 못 본다. **09-05~06 경에 다시
  받아 보면** 피드 노출이 0 인지, 노출은 있는데 안 눌린 것인지 갈린다. 그 둘은 대응이
  완전히 다르다.
